# Papers & Supplementary Documents (`papers/`)

Place PDF preprints, supplementary materials, or technical notes in this folder.

Once committed and pushed to GitHub, any file `papers/<filename>.pdf` becomes immediately downloadable at:

```text
https://hectormb100.github.io/papers/<filename>.pdf
```

For reproducible simulation codes and datasets accompanying submitted manuscripts, create a dedicated public repository under `@hectormb100` (see the root `README.md` for the 3-line terminal commands) and add a link in `../papers.html`.
